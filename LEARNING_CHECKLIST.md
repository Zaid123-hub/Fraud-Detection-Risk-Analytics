# Interview preparation checklist

Before presenting this project as completed, make sure you can explain each item:

- [ ] Why fraud data is often imbalanced
- [ ] Difference between precision, recall, F1-score, and accuracy
- [ ] Why transaction IDs should not be used as model features
- [ ] Why categorical columns need one-hot encoding
- [ ] Why numeric features are scaled in this pipeline
- [ ] What `class_weight="balanced"` does
- [ ] What a confusion matrix shows
- [ ] How the train/test split works
- [ ] Why the synthetic dataset is only for demonstrating the workflow
- [ ] What changes are needed before using real data in a serious setting
- [ ] Run the scripts yourself and verify the outputs before claiming completion
