# Fraud Detection & Transaction Risk Analytics

A beginner-friendly portfolio project demonstrating a reproducible transaction-risk workflow:
data inspection, exploratory analysis, feature engineering, model training, evaluation, and a small Streamlit dashboard.

## Important dataset note
`data/transactions_demo.csv` is **synthetic demonstration data**, generated for learning. It is not real customer or bank data and must not be described as a real-world fraud dataset. Results from synthetic data are illustrative only and do not demonstrate production fraud-detection performance.

## Features
- Python, pandas and NumPy for data handling
- Matplotlib for visual exploration
- A scikit-learn classification pipeline
- Evaluation with precision, recall, F1-score, confusion matrix and average precision
- Streamlit dashboard for exploring the demo data and model metrics
- CSV outputs suitable for further analysis in Excel or Power BI

## Setup
Use Python 3.10+.

### 1. Create and activate a virtual environment
macOS/Linux:
```bash
python3 -m venv .venv
source .venv/bin/activate
```
Windows:
```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
```

### 2. Install dependencies
```bash
python -m pip install -r requirements.txt
```

### 3. Generate a fresh synthetic dataset (optional)
From the project root:
```bash
python src/generate_data.py
```

### 4. Train and evaluate
```bash
python src/train_model.py
```
This creates evaluation summaries, predictions, and plots in `outputs/`.

### 5. Launch the dashboard
```bash
streamlit run dashboard/app.py
```
The dashboard reads the synthetic data and outputs generated by the training script.

## How to describe this honestly on a resume
Only describe the parts you have actually run, checked, and can explain. Until you complete the work, label it **In Progress**. Do not invent accuracy or performance numbers. Since the supplied data is synthetic, explain that clearly in interviews.
